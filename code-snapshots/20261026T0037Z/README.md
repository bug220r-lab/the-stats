# Reviewed source snapshot — 2026-10-26

This is a deliberately partial code and documentation recovery snapshot from the current Windows checkout of The Stats. It is published in the existing private repository as an additive directory on a separate branch. Existing repository files and the default branch are preserved.

The snapshot contains reusable application source, generic launcher/preparation/reproduction scripts, explicitly reviewed synthetic core tests, empty mapping/header templates, pinned dependency files, and reviewed operating documentation. Source code is copied unchanged. Documentation copies remove named user identities and source-derived data summaries where necessary; originals are unchanged.

This subset is not a standalone runnable application or a complete project backup. Some retained modules import omitted integration or view modules. The separate private recovery backup is needed for a full restore. Existing historical repository snapshots may contain earlier versions; this publication makes no claim about their contents.

No analytics exports, customer records, social captures, databases, generated outputs, backups, logs, handoff evidence, private fixtures, credentials, sessions, real identity configuration or environment are included. Top-level data/, outputs/, backups/, logs/, handoff/, test-results/, .streamlit/, .venv/ and caches are excluded. Artwork assets and unreviewed source-specific scripts/tests/docs are omitted conservatively.

Source schema names, relative asset paths, version labels, algorithm parameters and a public band handle used in parser rules remain where they are part of source logic. These references do not bundle their underlying evidence.

SOURCE_MANIFEST.json records published source sizes, SHA-256 hashes, original source hashes and documentation treatments. EXCLUSIONS.json records every omitted file within the reviewed code/documentation candidate directories. REVIEW.json records review controls and validation. The manifest does not enumerate private data directories because those directories were excluded from this code-publication task.

Validation: 168 synthetic core tests passed against this isolated copy (calculations, ingestion, storage, import preview, Apple Music mapping, TikTok mapping). Every retained Python file parsed; JSON templates parsed; CSV templates were verified header-only. The complete UI and omitted integration suite were not run.
